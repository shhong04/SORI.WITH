API Docs Analyze 결과 앱 UI Render

진행 순서 (~3–4분)

  1. 문제 — 합주 sync가 깨져도 원인이 안 보인다.
  2. 엔진 (모니터) — 터미널에서
    ./scripts/demo_analyze.sh http://127.0.0.1:8000
    또는 /docs에서 session 생성 → analyze 업로드.
  3. 세 줄 짚기 — tempo (onset+IOI) → alignment (DTW) → timing/relation.
  4. 제품 (폰) — 관객 A 방 만들기, 관객 B 코드 참가.
  5. 마무리 — 소리의 듣고·맞추고·진단 → 합주 연습 제품.

발표 전 체크

  • Render를 한 번 열어 cold start 깨우기
  • 로컬 API: uvicorn sori_with.api.main:app --host 0.0.0.0 --port 8000
  • 모니터 탭: /docs + /web/demo-analyze.html
  • 합성 음원은 스크립트가 자동 생성 (업로드 시연용)

관객 멘트

  • “지금 올리는 건 합성 합주 WAV + 악보입니다.”
  • “엔진이 템포·악보 정렬·파트 관계를 숫자로 냅니다.”
  • “폰 앱은 그 루프를 합주 UX로 묶은 프로토타입입니다.”
